One authority, three experiences

The bootstrapper and Companion own changes. The Gateway Web UI is a status and handoff surface because it runs inside the thing being controlled.

Do not conflate these controls

Outer mode versus inner command sandbox

Minimal / YOLO chooses the Gateway's Windows identity and session. MXC presets choose restrictions for individual commands after the Gateway is already running.

Gateway execution mode

Minimal or YOLO. Owned by the host launcher and Windows Companion. Establishes or removes the outer Agent User Session.

MXC command sandbox preset

Locked Down, Recommended, or Unprotected in current working implementations. Owned by the Gateway or Windows node for nested, per-command ProcessContainers.

Open product decision

Can YOLO be part of the managed Windows path?

The current first-step wording says YOLO runs without a session. The managed Windows direction says the local Gateway must remain in a dedicated Agent User Session with no uncontained fallback.

  • Recommended: keep Minimal as the managed path and make YOLO a separate advanced/unmanaged installation posture.
  • Alternative: redefine YOLO so it retains the Agent User Session, then specify what meaningful control distinguishes it from Minimal.
  • Do not silently turn a contained installation into native execution because the session is unavailable.
